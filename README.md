# 지환 & 서희 모바일 청첩장

2026년 10월 25일 수원 마이어스에서 열리는 지환과 서희의 결혼식을 위한 모바일 청첩장입니다.

## 주요 기능

- 순차 등장 및 인사 모션이 적용된 커플 인트로
- 결혼식 정보, 혼주 소개, 달력과 실시간 D-day
- 버튼·터치 이동과 확대 보기를 지원하는 사진 갤러리
- 카카오맵 SDK 기반 예식장 지도와 외부 지도 링크
- 안성 출발 전세버스 안내
- 계좌번호 접기/펼치기 및 복사
- D1에 저장되는 방명록 작성, 전체 보기, 비밀번호 삭제
- 카카오톡 등 링크 공유용 대표 이미지

## 실행

```bash
pnpm install
pnpm dev
```

## 환경 설정

카카오맵 JavaScript 앱 키는 `.env`의 `NEXT_PUBLIC_KAKAO_MAP_APP_KEY`로 관리합니다. 카카오 개발자 콘솔의 웹 플랫폼에 로컬 주소와 실제 배포 주소를 허용 도메인으로 등록해야 지도가 표시됩니다.
